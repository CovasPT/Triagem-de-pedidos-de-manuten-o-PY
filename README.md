# Triagem de pedidos de manutenção (IA)

Projeto final de Inteligência Artificial: classificar se um pedido de manutenção é urgente,
comparando árvore de decisão, Random Forest e MLP com o custo médio (FN = 4 × FP).

- `notebook.ipynb` — notebook do trabalho (secções do enunciado, com TODO a preencher)
- `dados/` — CSV fornecidos (não editar à mão)
- `README.txt` / `requirements.txt` — instruções de execução para a entrega

Executar: `python -m pip install -r requirements.txt` e depois *Restart & Run All* no notebook.
